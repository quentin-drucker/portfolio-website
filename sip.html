Computational World-Building

A wabi-sabi-inspired system for generative worlds. A still photograph influences a procedurally generated, explorable world.

In progress. First milestone: terrain.

The idea

A photograph steers the world. It doesn’t rebuild it.

The photograph is not reconstructed and this is not photogrammetry. The image is read for a small set of understandable features, and those features become parameters that bias how a world is generated.

The project is both artistic and technical: the variation rules come from wabi-sabi, and the system that applies them is written in C++ for Unreal Engine.

Pipeline

From one image to a place you can walk through.

  1. PhotographA single still image is the input.
  2. Image analysisThe image is measured.
  3. FeaturesBrightness, color, contrast, density, texture, structure, mood.
  4. ParametersFeatures become generation parameters.
  5. Unreal C++The generation system.
  6. TerrainFirst milestone.
  7. Variation rulesWabi-sabi rules bend the result.
  8. ScatteringPlacement across the terrain.
  9. Materials and weathering
  10. Lighting, fog, atmosphere
  11. Sound
  12. Explorable environmentFirst-person.
Variation rules

Wabi-sabi as a set of rules.

The generator leans toward these qualities instead of clean, uniform output.

  • Asymmetry
  • Irregularity
  • Imperfection
  • Transience
  • Weathering
  • Non-uniform repetition
  • Controlled disorder
  • Atmospheric softness
