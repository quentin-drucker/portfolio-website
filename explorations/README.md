# Style explorations

Five standalone visual directions for the portfolio, all using the same real
content. Open `index.html` here for a side-by-side gallery.

Each file is self-contained (inline CSS and JS, Google Fonts only) and shares no
code with the live site, so nothing here affects `index.html` at the repo root.

| File | Direction | Bold move |
|---|---|---|
| `01-weathered.html` | Wabi-sabi: stone paper, ink, moss, asymmetric | Ink-wash ridges drawn fresh each visit; gold kintsugi seam |
| `02-viewport.html` | Game-engine editor shell | Live, draggable, parameterized wireframe terrain |
| `03-contact-sheet.html` | Photography: film strip, edge print | Grease-pencil selection of project frames |
| `04-signal.html` | Swiss poster, one ultramarine colour | Pointer-reactive flow field behind an oversized name |
| `05-refined.html` | Current dark/cyan identity, disciplined | Seed-driven topographic hero (from the existing seed demo) |

All image areas are labelled placeholders or generated stand-ins, not real
project media. Process followed: Anthropic's frontend-design guidance (token
plan per direction, checked against generic defaults, screenshot critique),
with accessibility basics (focus states, reduced motion, no horizontal scroll)
checked at 1440px and 390px.

`previews/` holds the gallery thumbnails (1440 × 900 first screen).
