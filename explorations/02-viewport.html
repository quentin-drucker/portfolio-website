Computational World-Building

A wabi-sabi-inspired system for generative worlds. A still photograph is analyzed for a small set of understandable features, and those features become parameters that bias an explorable environment built in Unreal Engine with C++. The photograph shapes the world. It is not reconstructed.

Photographsource image
Featuresbrightness, color, contrast, density, texture
Parametersnumeric + categorical
TerrainUnreal C++, first milestone
Variationasymmetry, weathering
Atmospherelight, fog, sound
Media placeholder: source photograph beside the generated environment

Builds on an earlier UE5 prototype, a PCG-driven forest with ambient sound, atmospheric fog and first-person exploration. This year's work moves the generation logic into C++.
